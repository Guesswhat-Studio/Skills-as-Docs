# Release Notes

Use this skill to convert a list of product changes into release notes for internal or public audiences.

## Workflow

1. Identify the audience and release channel.
2. Group changes by user impact.
3. Write concise bullets with plain language.
4. Call out breaking changes, migrations, or known limitations.
5. Ask for missing context when the input does not identify impact.

## Approval Path

Promote this skill to `approved` only after it has produced useful notes from at least two real releases.
