Public Skill Intake Review

Use Git as the trust layer between public skill discovery and team installs.

A research operations team wants Anthropic's public skill-creator, but shared installs are blocked until the package has provenance, evidence, review, CI, and a Git history.

Scenario

Maya owns the team's shared skill library. Analysts use Codex, Claude Code, and Antigravity for repeated research workflows, and they want skill-creator to help turn those workflows into reusable internal skills.

Public skills are allowed as inputs, but approved installs must come from the team's Git repository.

Live Source

Load anthropics/skills in the manager. A local Skills Charter scan on 2026-05-20 found 17 packages, including multi-file packages such as skill-creator, docx, pptx, xlsx, and canvas-design.

The point is not that the upstream repo is unsafe. The point is that real skill packages include enough routing, scripts, assets, links, and supporting material to deserve review before internal approval.

Demo Script

  • Open the manager and say: this is the Git-backed review surface, not the runtime.
  • Import anthropics/skills from Workspace settings.
  • Select skills/skill-creator/SKILL.md and show its package scope.
  • Mark it as candidate and public_import, with owner and source URL.
  • Run policy and explain that warnings create review work in Git.
  • Show the evidence note and prepare the PR handoff.
  • Show install snippets only after approval.

Install After Approval

npx skills add org/research-skills --skill skill-creator -g -a codex
npx skills add org/research-skills --skill skill-creator -g -a claude-code
npx skills add org/research-skills --skill skill-creator -g -a antigravity

Claim

Skills Charter does not replace public repositories or npx skills. It gives teams a Git-backed path to internalize public skills without turning installation into blind trust.
